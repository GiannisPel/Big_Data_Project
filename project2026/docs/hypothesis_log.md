## Hypothesis Log conclusion

### Q1 Result Check

Μετά την εκτέλεση του Q1, η υπόθεση κάπως επιβεβαιώθηκε, επειδή τα top-K αποτελέσματα έδειξαν ότι οι περισσότερες κούρσες γίνονται τις βραδινές ώρες (21, 22, 23)

## Q2 Hypotheses

Πριν την εκτέλεση του Q2, περίμενα ότι στο προσωπικό μου ωριαίο παράθυρο [21, 22, 23, 0] οι πιο αργές ή λιγότερο αποδοτικές διαδρομές θα εμφανιστούν κυρίως στην ώρα 00:00.

Επίσης, περίμενα ότι η ώρα 00:00 θα έχει υψηλότερη μέση ταχύτητα από τις 21:00, επειδή μετά τα μεσάνυχτα η κυκλοφορία μπορεί να είναι χαμηλότερη. 

### Q2 Result Check

Η αρχική υπόθεση επιβεβαιώθηκε κάπως.

Σύμφωνα με τα αποτελέσματα του Q2. Η ώρα 21:00 είχε το μεγαλύτερο πλήθος διαδρομών 694,717, άρα φαίνεται να είναι η πιο έντονη ώρα για ζήτηση.

Ωστόσο, η υπόθεση ότι η ώρα 00:00 θα έχει καθαρά υψηλότερη ταχύτητα δεν επιβεβαιώνεται από το aggregate αποτέλεσμα. Η ώρα 00:00 έχει agg_speed_kmh = 23.5609, χαμηλότερο από τις ώρες 21, 22 και 23 στο συγκεκριμένο output.

Τα extreme records επιβεβαιώνουν την υπόθεση ότι υπάρχουν ανωμαλίες. Στον πίνακα fastest, εμφανίζονται διαδρομές με υπερβολικά μεγάλα trip_distance_km και ταχύτητες εκατομμυρίων km/h, κάτι που δεν είναι ρεαλιστικό. Όπως και τα slowest_per_km περιλαμβάνουν πολύ μικρές αποστάσεις με πολύ μεγάλη διάρκεια, που και πάλι δεν είναι ρεαλιστικό.

## Q3 hypotheses

Πριν την εκτέλεση του Q3, περίμενα ότι τα μεγαλύτερα συνολικά έσοδα θα εμφανιστούν κυρίως σε αεροδρόμια και κεντρικές ζώνες του Manhattan. Τα αεροδρόμια πιθανόν έχουν ακριβότερες/μεγαλύτερες διαδρομές.

Επίσης, περίμενα ότι τα rankings total_revenue, revenue_per_mile και revenue_per_minute δεν θα είναι ίδια, επειδή τα συνολικά έσοδα μετρούν κυρίως όγκο, ενώ τα άλλα δύο μετρούν αποδοτικότητα.

### Q3 Result Check

Η υπόθεση επιβεβαιώθηκε.

Άρα τα συνολικά έσοδα και η αποδοτικότητα δείχνουν διαφορετικά πράγματα: τα airports κυριαρχούν στα συνολικά έσοδα.
